# 🪙 CoinRates.live - Free Real-Time Cryptocurrency Converter

Official website: **[https://coinrates.live](https://coinrates.live)**

A modern, lightning-fast, and completely free live cryptocurrency converter web application. Built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Vite**.

---

## 🚀 Key Features

- **⚡ Live Exchange Rates**: Connected directly to the Binance REST ticker feed and global fiat exchange rate APIs for real-time price updates.
- **🔄 Instant Bidirectional Conversion**: Effortlessly convert between Crypto-to-Crypto, Crypto-to-Fiat (USD, EUR, GBP, INR, JPY, CAD, AUD, etc.), and Fiat-to-Crypto.
- **🔗 Shareable Pair URLs**: Visit `/?from=BTC&to=USD` or `/?from=ETH&to=INR` with real-time browser URL synchronization for instant sharing.
- **📊 Interactive Sparkline Chart**: Toggle between 24H, 7D, 30D, and 1Y timeframes with hover price points and percentage changes.
- **🌐 Global Multi-Currency Matrix**: See what 1 unit of your selected crypto or fiat is worth across top global currencies simultaneously.
- **⛽ Ethereum Gas Fee Tracker**: Real-time Gwei tracker for Slow, Standard, and Fast network transactions.
- **🧭 Crypto Fear & Greed Index**: Gauge current market sentiment and mood in real time.
- **⭐ Pinned Favorites & Recents**: Star your favorite currency pairs (BTC/USD, ETH/EUR, SOL/INR) saved in localStorage for 1-click access.
- **🏷️ Slippage & Fee Simulation**: Test net conversion payouts after 0.1%, 0.5%, or 1.0% exchange or swap fees.
- **🔍 SEO & Social Ready**: Full Open Graph, Twitter Cards, Canonical tags, and Google WebApplication schema markup.

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
```

## 🚢 Deploying to `coinrates.live`

You can deploy this project for free in 1 minute using:
- **Vercel**: Import your GitHub repository, framework preset: `Vite`, add custom domain `coinrates.live`.
- **Cloudflare Pages**: Connect repository, build command `npm run build`, build output `dist`, bind custom domain `coinrates.live`.
- **Netlify**: Drag & drop `dist` folder or connect Git repo.
